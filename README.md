# 행초첩 v1.0

아이패드 Safari용 개인 서예 연습 PWA입니다. 앱스토어 등록이나 Apple 개발자 계정이 필요하지 않습니다.

## 실행 / 설치

1. `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icons/` 폴더를 **함께** 정적 HTTPS 호스팅에 올립니다 (GitHub Pages, Cloudflare Pages, Netlify 등).
2. iPad Safari에서 배포된 HTTPS 주소를 열고 **공유 → 홈 화면에 추가 → 웹앱으로 열기**를 선택합니다.
3. 처음 설치한 후 인터넷이 연결된 상태에서 한 번 열어 앱 파일이 오프라인 캐시되도록 합니다.
4. 홈 화면 아이콘을 눌러 실행합니다.

**주의:** ZIP 압축을 풀고 `file://`로 HTML 파일을 여는 것만으로는 PWA 설치 및 Service Worker 오프라인 지원이 활성화되지 않습니다. HTTPS 주소로 게시해야 합니다.

## 고전 법첩 원본 이미지

예시 `永`은 위키미디어 공용의 공개 도메인으로 표시된 고전 필적 이미지 **`File:神龍蘭亭永.jpg`** 를 실행 시 원격으로 표시합니다.
- 출처: https://commons.wikimedia.org/wiki/File:神龍蘭亭永.jpg
- 라이선스: Wikimedia Commons 페이지에서 Public Domain / PD-Art 표기 확인 (2026-10-24)
- 원격 연결이 안 되거나 오프라인이면 이미지는 표시되지 않을 수 있습니다.

원본을 **오프라인**으로 쓰려면 해당 출처에서 이미지를 사용자가 내려받고, 앱의 **법첩 관리 → 이미지 가져오기**에서 해당 파일을 선택하세요. 글씨본 영역을 드래그로 선택하고 한자·출처·단위를 지정해 저장합니다. 이미지 자체가 IndexedDB에 저장됩니다. 임의의 법첩 이미지는 이용 조건을 직접 확인해야 합니다.

이 버전은 저작권 상태가 확인된 1개 샘플 외의 고전 필적 이미지를 임의로 묶어 제공하지 않습니다. 다른 글씨본은 사용자가 직접 원본을 추가할 수 있습니다.

## 기능

- 한 글자/문구/전체 단위 필터링
- iPad Apple Pencil 및 터치 포인터 필기 (마우스도 가능)
- 회색 원본 농도 및 펜 굵기 변경
- 마지막 획 종료 후 1.2/2/3/5초 자동 넘김 (꺼짐 가능)
- 이전/다음/획 취소/지우기
- 개인 이미지 자르기 및 기기 내부 저장 (IndexedDB)
- 앱 셸 캐시(오프라인), 마지막 선택 글씨본과 설정 기억

## 현재 한계

- 자동 넘김은 정확한 글자 완성을 인식하지 않고 마지막 획 뒤 대기시간만 사용합니다.
- 자동 넘김 이후 필기 흔적은 보존하지 않습니다. 이전으로 돌아가도 빈 연습판이 나옵니다.
- 기본 예시 이미지는 온라인 리소스이므로 오프라인에서는 별도로 가져와야 합니다.
- Apple Pencil 압력에 따라 선 굵기가 변하는 캘리그래피 붓은 아직 미구현이고 고정 두께의 필기입니다.
- IndexedDB는 사용자 데이터 삭제나 시스템 정리로 소실될 수 있으므로 원본 이미지를 백업하세요.
