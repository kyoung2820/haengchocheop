# 行草帖 v2.0 — iPad 행초서 연습 PWA

## 포함 기능
- iPad Safari 전체화면 웹앱, Apple Pencil/손가락 입력, 펜 압력에 따른 선 굵기
- 한 글자 / 문구 연습, 순차 / 랜덤(한 바퀴 중 중복 최소화) / 즐겨찾기 랜덤
- 농도·선 굵기·자동 넘김 대기 시간 조절, 획 취소·지우기·이전/다음
- 이미지 여러 개 또는 NCCU 초서 데이터셋의 폴더를 직접 선택하여 **iPad 브라우저 안의 IndexedDB**에 저장
- 한자명이 붙은 폴더를 기준으로 문자 라벨 자동 인식
- 기본 데모 한자 다수 제공(단, 시스템 서체이며 고전 법첩 원본은 아님)
- 문구 목록 사용자 편집, 미등록 문구 글자는 데모 서체 대체
- 앱 쉘 오프라인 캐시

## 중요한 데이터셋 제한
**원본 데이터셋 이미지는 ZIP에 들어 있지 않습니다.** 원본 대용량 데이터셋을 이 제작 환경에서 다운로드할 수 없었기 때문입니다. 브라우저에서 데이터셋을 직접 선택해 추가해야 하며, 파일 접근과 기기 저장 공간에 제한이 있습니다. 이미지 출처는 사용자가 가져오기 화면에서 설정합니다. 오프라인에서 실제 법첩 이미지 연습을 하려면 먼저 가져와야 합니다.

NCCU Cursive Chinese Calligraphy Dataset: https://github.com/nccuviplab/CursiveChineseCalligraphyDataset
해당 저장소의 README에 따르면 Training/문자/이미지 형식, 원본 96×96 이미지, 5,301개 문자 클래스입니다. 이용 전에 저장소 LICENSE와 데이터 제공 조건을 확인해 주세요. 다른 데이터셋도 문자별 폴더 또는 파일명에 한자 한 글자가 있으면 작동합니다.

## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. **압축을 푼 폴더 안의 내용물** `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icons/`를 GitHub 저장소 **루트**에 올립니다.
3. Commit changes. 기존 Pages 설정(`main`, `/(root)`)은 바꾸지 않습니다.
4. GitHub Actions에서 배포 완료 후 `https://kyoung2820.github.io/haengchocheop/`에 접속합니다.
5. iPad Safari 공유→홈 화면에 추가→웹앱으로 열기.
6. 오래된 앱이 보이면 Safari의 웹사이트 데이터/캐시를 새로고침하거나 앱을 완전히 종료 후 다시 실행하세요. v2 캐시 이름은 이전 버전과 다릅니다.

## 데이터 가져오기
NCCU 데이터셋의 저장소 페이지에서 다운로드한 파일을 풀고, `Cursive_Chinese_Calligraphy_Dataset/.../Training/` 아래의 **문자 이름 폴더들이 포함된 폴더**를 선택합니다. Safari의 폴더 선택 가능 여부는 iPadOS 버전에 따라 달라질 수 있어 데스크톱에서 먼저 데이터 가져오기를 시험하는 것이 좋습니다. 한 번에 최대 2,500 이미지를 가져오며, 동일 기기의 IndexedDB에 저장됩니다. 여러 기기 사이에는 자동 동기화되지 않습니다.

## 알려진 한계
- 각 데이터셋 이미지의 작품명·서예가 정보가 없으면 임의로 부여하지 않음
- 개별 이미지의 필획 완성 판정은 하지 않으며 시간 경과로만 넘김
- 이미지를 혼합하여 구성한 문구는 실제 법첩의 연속 획이 아님
- 브라우저 저장 공간이 부족하면 가져오기 실패할 수 있음
- 대량 이미지 폴더 선택은 기기별로 브라우저에서 다르게 지원될 수 있음
